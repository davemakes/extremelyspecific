Disable the Essential Space button on Nothing Phones

  • 25 October 2026
  • smartphone

The Problem

The Nothing Phone 3a introduced an extra “Essential Space” button that takes screenshots and records audio to be fed into an AI memo app. It’s very easy to accidentally take lots of meaningless screenshots, or screenshots of sensitive information, and an accidental press can wind up recording private conversations to be automatically fed into an AI for transcription.

There are some options to mitigate these problems, but no built-in way to completely disable the button. But we can hack it.

The Solution

This guide from Reddit is what worked for me on my Nothing Phone 3. It feels a little advanced because you have to do some terminal commands on your phone, but it’s not as scary as it sounds. I’ve reproduced the steps here with some missing details filled in.

  1. Install the app Termux. It seems like the Google Play version is limited, and the best way to get it is through GitHub or F-Droid
  2. In Termux, run the command pkg install android-tools
  3. Enable Developer Options:
    • Open your settings app
    • Scroll to the bottom and tap About Phone
    • Find the “Build number” info. On my Android 17 phone, I have to tap on “Android version” under “Device Details” to reveal it
    • Tap on “Build number” 7 times and enter your password or PIN when prompted.
  4. In Settings > System > Developer Options, under “Debugging” do:
    • Enable USB debugging
    • Enable Wireless debugging
    • Tap on Wireless debugging
    • Tap “Pair device with pairing code”
    • Take a note of the Wi-Fi pairing code
    • Take a note of the 5 digit number at the end of the IP address & port
  5. In Termux, run the command adb pair localhost:PORT where PORT is that 5 digit number
  6. Enter the Wi-Fi pairing code when prompted
  7. Close the device pairing screen and note the 5 digit port number displayed on the main Wireless Debugging display.
  8. In Termux, run the command adb connect localhost:PORT where PORT is that new 5 digit number
  9. You should be connected now. Run the following commands in Termux:
adb shell pm disable-user --user 0 com.nothing.ntessentialspace
adb shell pm disable-user --user 0 com.nothing.ntessentialrecorder
  1. Back in settings, disable USB debugging and Wireless debugging. Close Termux.

And that’s it! Now the Nothing Phone’s extra button truly does nothing.

Optional Steps

I haven’t tried these, but apparently you can remap the button using an app called KeyMapper from the Google Play store.

If you want to re-enable the Essential Space button, in Termux use these commands:

adb devices
adb shell pm enable --user 0 com.nothing.ntessentialspace
adb shell pm enable --user 0 com.nothing.ntessentialrecorder
